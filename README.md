# Closed-Loop-Control-of-AC-Motor-Using-Phi-Constant-method
Closed Loop Control of AC Motor Using Phi Constant method
The focus of this method is to keep the flux of the air gap steady at a constant amount
The flux is estimated via a flux estimator that has been developed
A hysteresis control scheme has been utilized to keep the relation between stator current and slip speed constant when frequency changes due to a variance in speed
Alongside this, an open loop variant of the simulation has been added to the repository which utilizes a compensation method for slip speed at lower frequencies
